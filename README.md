# Backend Service (NestJS)

## Description

This project is built using the **NestJS framework**, a progressive Node.js framework for building efficient and scalable server-side applications.

---

## 🚀 Getting Started

### Install Dependencies

```bash
npm install
```

---

## ▶️ Running the Application

All services in this project can be run together using the following command:

```bash
npm run start:dev
```

> ⚠️ Detail of each service and scripts configuration can be found in `package.json`.
